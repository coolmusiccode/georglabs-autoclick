# GeorgLabs AutoClicker Website

Statische Landingpage für `autoclicker.georglabs.com`.

## Dateien
- `index.html` – Seiteninhalt
- `styles.css` – responsives Dark/Purple-Design
- `script.js` – mobiles Menü und Jahreszahl
- `downloads/README.txt` – Hinweis zum späteren Release-Upload

## Deployment
1. Alle Dateien und Ordner im ZIP entpacken.
2. Den Inhalt dieses Ordners als Website-Root bei Netlify hochladen oder ins passende GitHub-Repository pushen.
3. In Netlify die Domain `autoclicker.georglabs.com` als Custom Domain hinzufügen.
4. Beim DNS-Anbieter den von Netlify angezeigten DNS-Eintrag für `autoclicker` setzen.

## Download veröffentlichen
Das Download-Element ist absichtlich noch deaktiviert. Lege dein geprüftes Release-Paket später z. B. als
`downloads/GeorgLabs-AutoClicker.zip` ab und ändere in `index.html` den Download-Link auf
`downloads/GeorgLabs-AutoClicker.zip`. Passe danach den Button-Text und die FAQ an.

Die Website behauptet bewusst keine Versionsnummer, Lizenz oder Release-Verfügbarkeit.
